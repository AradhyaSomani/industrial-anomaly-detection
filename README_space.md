# Industrial Anomaly Detection

Unsupervised defect detection and localization on MVTec AD. Models were trained only on defect-free images; anything that doesn't look normal is flagged.

Upload an image (or pick an example), leave the category on Auto-detect, and inspect the heatmap and flagged regions.

Code, results and write-up: https://github.com/AradhyaSomani/industrial-anomaly-detection
